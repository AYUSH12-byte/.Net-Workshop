# .NET C# Practical Tasks

This repository contains my practical tasks completed using **C# and .NET** in **JetBrains Rider**.

## Technologies Used

* C#
* .NET
* JetBrains Rider
* Git & GitHub

## Tasks Completed

### Task 1: Variables and String Interpolation

* Declared a `string` variable for the username.
* Declared an `int` variable for a lucky number.
* Used string interpolation to display the values.

### Task 2: Constants

* Created a `Circle` class.
* Declared a constant `PI` with a value of `3.14`.
* Demonstrated that a constant value cannot be modified.
* Added methods to calculate the area and perimeter of a circle.

### Task 3: Data Types and Type Conversion

* Used different C# data types:

  * `byte`
  * `short`
  * `int`
  * `long`
  * `float`
  * `double`
  * `decimal`
  * `char`
  * `bool`
* Converted an integer to a string.
* Converted a string to a double.
* Displayed the types and values.

### Task 4: Array and Array Methods

* Created an integer array containing 5 numbers.
* Used `Array.Sort()` to sort the array.
* Used `Array.Reverse()` to reverse the array.
* Used a `for` loop to display the elements.
* Used `Array.IndexOf()` to find an element's position.

### Task 5: DateTime and TimeSpan

* Created a `DateTime` variable for a birthdate.
* Used `DateTime.Now` to get the current date and time.
* Used `TimeSpan` to calculate the difference between dates.
* Calculated age in years.
* Added 10 days to the birthdate.

### Task 6: Generic Collections

* Created a `List<string>` containing fruit names.
* Added and removed items from the list.
* Used a `foreach` loop to display the fruits.
* Created a `Dictionary<int, string>` for fruit IDs and names.
* Added a new dictionary entry.
* Displayed all key-value pairs.
